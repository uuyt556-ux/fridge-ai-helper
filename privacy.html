개인정보처리방침

시행일 2026년 11월 26일 · 최종 개정일 2026년 11월 26일

‘냉장고 파먹기 — AI 레시피·장보기 도우미’(앱 이름 ‘냉장고AI’, 이하 “앱”)는 이용자의 개인정보를 소중히 다루며, 아래와 같이 개인정보처리방침을 두고 있습니다. 이 방침은 앱과 웹 주소 https://uuyt556-ux.github.io/fridge-ai-helper/ 에 함께 적용됩니다.

한눈에 보기

· 회원가입이 없고, 운영자의 서버·데이터베이스가 없습니다. 운영자는 이용자의 정보를 수집·보관하지 않습니다.

· 냉장고·식재료 사진은 레시피 분석을 위해서만 Google Gemini API로 전송되며, 앱과 운영자는 사진을 저장하지 않습니다.

· 입력한 Gemini API 키와 설정값은 이용자 기기의 브라우저(localStorage)에만 저장됩니다.

· 광고·분석(트래커) 도구를 쓰지 않으며, 위치·연락처 등 기기 정보를 수집하지 않습니다.

1. 수집하는 정보와 이용 목적

앱은 별도의 회원가입 절차가 없고 운영자의 서버로 아무 정보도 보내지 않습니다. 이용자가 앱 화면에서 직접 넣은 다음 정보만, 그 자리에서 기능을 수행하는 데 사용합니다.

항목어디에 쓰나어디에 저장되나
냉장고·식재료 사진 (이용자가 선택한 파일, 최대 3장) 사진 속 재료를 인식해 레시피와 장보기 목록을 만들기 위해 Google Gemini API로 전송 저장하지 않음. 브라우저 메모리에만 있다가 앱을 닫거나 새로고침하면 사라짐
재료·조건 입력값 (텍스트) 레시피 생성 요청 내용으로 사용 저장하지 않음 (화면을 닫으면 사라짐)
Gemini API 키 (이용자가 직접 발급·입력) 이용자 기기에서 Google Gemini API를 호출하기 위해 이용자가 ‘이 브라우저에 저장’을 체크한 경우에만 해당 기기 브라우저의 localStorage
앱 설정값 (선택한 AI 모델, 무료 체험 횟수) 앱 화면 상태 유지 해당 기기 브라우저의 localStorage

이 외에 이름·전화번호·이메일·주소·위치·연락처·사진첩 전체·결제정보 등을 요청하거나 수집하지 않습니다. 앱은 카메라나 사진첩에 직접 접근하지 않고, 이용자가 파일 선택 창에서 고른 파일만 읽습니다.

2. 기기에 저장되는 정보(localStorage)

앱은 서버 없이 동작하기 위해 아래 값만 이용자 브라우저에 저장합니다. 모두 이용자 기기 안에만 있으며 운영자에게 전송되지 않습니다.

  • fridgeai.geminiKey.v1 — 이용자가 입력하고 저장을 선택한 Gemini API 키
  • fridgeai.model.v1 — 선택한 AI 모델 이름
  • fridgeai.saveKey.v1 — API 키 저장 여부 설정
  • fridgeai.freeLeft.v1 — 남은 무료 체험 횟수
  • fridgeai.installDismissed.v1 — 홈 화면 설치 안내 배너를 닫았는지 여부

이 값들은 브라우저의 ‘인터넷 사용 기록/사이트 데이터 삭제’ 또는 앱 삭제로 언제든 직접 지울 수 있습니다.

3. 제3자 제공 및 처리위탁

앱은 레시피 분석을 위해 이용자가 넣은 사진과 재료 텍스트, 그리고 이용자의 API 키를 Google LLC의 Gemini API(generativelanguage.googleapis.com)로 전송합니다. 이는 이용자가 ‘레시피 받기’를 눌렀을 때만 일어나며, 해당 정보의 처리는 Google의 정책을 따릅니다.

  • Google 개인정보처리방침: https://policies.google.com/privacy
  • Gemini API 약관: https://ai.google.dev/gemini-api/terms

앱은 위 목적 외에 개인정보를 제3자에게 판매·대여·제공하지 않습니다. 광고 네트워크, 분석 도구, 소셜 로그인을 사용하지 않습니다.

4. 호스팅

앱은 GitHub Pages(https://github.io)에서 정적 파일로 제공됩니다. 페이지를 여는 과정에서 접속 IP·브라우저 정보 등이 호스팅 사업자인 GitHub, Inc.의 서버에 기록될 수 있으며, 이는 GitHub의 개인정보처리방침(링크)에 따라 처리됩니다. 운영자는 이 기록에 접근하거나 별도로 보관하지 않습니다.

5. 보관 기간과 파기

운영자는 이용자의 개인정보를 보관하지 않으므로 파기할 대상이 없습니다. 기기에 저장된 값(2항)은 이용자가 브라우저 데이터를 삭제하거나 앱을 삭제하는 즉시 사라집니다. 사진과 입력값은 요청 처리 후 남지 않습니다.

6. 이용자의 권리

  • 앱 설정 화면에서 저장된 API 키를 지우거나 ‘저장하지 않음’으로 바꿀 수 있습니다.
  • 브라우저 설정에서 사이트 데이터를 삭제하면 저장된 값이 모두 지워집니다.
  • 사진·재료 입력을 하지 않으면 어떤 정보도 외부로 전송되지 않습니다(데모 모드로 기능 체험 가능).

7. 아동의 개인정보

앱은 만 14세 미만 아동을 주 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다. 아동이 이용하는 경우 보호자의 지도 아래 이용해 주세요.

8. 안전성 확보 조치

앱과 주소는 HTTPS로만 제공되며, API 키는 운영자 서버가 아닌 이용자 기기에만 있습니다. 다만 이용자가 API 키를 다른 사람과 공유하거나 공용 기기에서 저장한 경우 노출될 수 있으므로, 공용 기기에서는 저장하지 않기를 권합니다.

9. AI 생성 결과의 한계

레시피·장보기 목록은 AI가 만든 참고 정보입니다. 재료의 상태·유통기한·알레르기 정보는 조리 전에 반드시 직접 확인해 주세요. 이는 개인정보와 별개로 앱의 이용 조건에 해당합니다.

10. 방침의 변경

법령이나 서비스 내용이 바뀌면 이 페이지를 통해 개정 내용과 시행일을 알립니다. 중요한 변경이 있을 때는 앱 화면 또는 이 페이지에 미리 안내합니다.
